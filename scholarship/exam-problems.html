1. Palindrome Checker with Optimization

Medium

Problem Statement:

Given a function that checks if a string is a palindrome by reversing the string and comparing, analyze its efficiency and create an optimized version. Handle edge cases and provide comprehensive testing.

Example Input: "racecar", "hello", "", "a"

Expected Skills: Code tracing, algorithm optimization, edge case handling

Optimal Solution Approach:

  1. Two-pointer technique: Compare characters from start and end moving inward
  2. Early termination: Return false immediately when mismatch found
  3. Case handling: Consider empty strings, single characters
  4. Space optimization: No additional string creation needed
def isPalindrome(s): if len(s) <= 1: return True left, right = 0, len(s) - 1 while left < right: if s[left] != s[right]: return False left += 1 right -= 1 return True

Complexity Analysis:

  • Original (naive) approach: O(n) time, O(n) space (creates reversed string)
  • Optimized approach: O(n) time, O(1) space
  • Best case: O(1) when first and last characters differ
  • Worst case: O(n) when string is palindrome or differs at center

Scholarship-Level Analysis:

  • Discuss why space optimization matters for large strings
  • Compare with other approaches (recursive, using built-in reverse)
  • Explain early termination benefits
  • Consider Unicode and case-sensitivity variations

2. Longest Common Substring

Hard

Problem Statement:

Find the longest common substring between two strings. Optimize for both time and space complexity.

Example: "ABABC" and "BABCA" → "BABC" (length 4)

Expected Skills: Dynamic programming, space optimization, algorithm comparison

Multiple Solution Approaches:

  1. Brute Force: Check all substrings - O(n³) time
  2. Dynamic Programming: 2D table approach - O(n²) time, O(n²) space
  3. Space Optimized DP: Use rolling array - O(n²) time, O(n) space
  4. Suffix Array/Tree: Advanced approach - O(n log n) time

DP Solution Analysis:

  • Time Complexity: O(m × n) where m, n are string lengths
  • Space Complexity: O(min(m, n)) with optimization
  • Recurrence: dp[i][j] = dp[i-1][j-1] + 1 if chars match, else 0

3. Knight's Minimum Moves

Medium

Problem Statement:

Calculate the minimum number of moves for a knight to travel from one square to another on an N×N chessboard. Handle multiple queries efficiently.

Input: Board size N, start position (x1,y1), end position (x2,y2)

Output: Minimum number of moves

BFS Solution Approach:

  1. Model as graph: Each square is a node, knight moves are edges
  2. BFS from start: Guarantees shortest path in unweighted graph
  3. 8 possible moves: Knight's L-shaped movement pattern
  4. Boundary checking: Ensure moves stay within board
from collections import deque def knightMinMoves(n, start, end): if start == end: return 0 moves = [(-2,-1), (-2,1), (-1,-2), (-1,2), (1,-2), (1,2), (2,-1), (2,1)] queue = deque([(start[0], start[1], 0)]) visited = set([start]) while queue: x, y, dist = queue.popleft() for dx, dy in moves: nx, ny = x + dx, y + dy if (0 <= nx < n and 0 <= ny < n and (nx, ny) not in visited): if (nx, ny) == end: return dist + 1 queue.append((nx, ny, dist + 1)) visited.add((nx, ny)) return -1 # Should never reach here on valid board

Complexity Analysis:

  • Time Complexity: O(N²) - worst case visits all squares
  • Space Complexity: O(N²) - for visited set and queue
  • Optimal: BFS guarantees minimum moves (shortest path)
  • Alternative: A* with Manhattan distance heuristic for larger boards

Test Cases to Consider:

  • Same position: (1,1) to (1,1) → 0 moves
  • Adjacent squares: Often require 3 moves due to knight movement
  • Opposite corners: Maximum distance on board
  • Minimum board size: 4×4 (smaller boards may have unreachable squares)

4. 0/1 Knapsack Problem

Medium

Problem Statement:

Given items with weights and values, and a knapsack capacity, find the maximum value that can be achieved. Items cannot be split.

Example: Capacity=5, Items=[(weight=1,value=3), (2,5), (5,7)] → Max value=8

Expected Skills: DP optimization, space complexity reduction, solution reconstruction

Progressive Solution Development:

  1. Recursive with Memoization: Top-down approach
  2. 2D DP Table: Bottom-up with full table
  3. Space Optimized: 1D array using rolling technique
  4. Solution Tracking: Reconstruct which items were selected
def knapsack_optimized(capacity, weights, values, n): # Space optimized DP - O(capacity) space dp = [0] * (capacity + 1) for i in range(n): # Traverse backwards to avoid using updated values for w in range(capacity, weights[i] - 1, -1): dp[w] = max(dp[w], dp[w - weights[i]] + values[i]) return dp[capacity]

Complexity Analysis:

  • Time Complexity: O(n × capacity) for all approaches
  • Space Complexity:
    • 2D DP: O(n × capacity)
    • Space optimized: O(capacity)
    • With solution tracking: O(n × capacity)
  • Pseudo-polynomial: Complexity depends on capacity value, not input size

Scholarship Analysis Points:

  • Explain why greedy approach fails (value/weight ratio)
  • Discuss space-time tradeoff between optimized and solution-tracking versions
  • Compare with fractional knapsack (greedy works there)
  • Mention NP-completeness and why DP is pseudo-polynomial

5. Sliding Window Maximum

Hard

Problem Statement:

Given an array and window size k, find the maximum element in each sliding window. Extend to handle minimum, sum, and multiple queries efficiently.

Example: [1,3,-1,-3,5,3,6,7], k=3 → [3,3,5,5,6,7]

Expected Skills: Deque usage, amortized complexity analysis, data structure design

Solution Approaches:

  1. Brute Force: Check each window - O(nk)
  2. Deque (Monotonic Queue): Maintain decreasing order - O(n)
  3. Segment Tree: Range max queries - O(n log n)
  4. Sparse Table: Precomputed range queries - O(n log n) preprocessing
from collections import deque def sliding_window_maximum(nums, k): dq = deque() # Store indices result = [] for i in range(len(nums)): # Remove indices outside current window while dq and dq[0] <= i - k: dq.popleft() # Remove smaller elements from rear while dq and nums[dq[-1]] <= nums[i]: dq.pop() dq.append(i) # Add to result if window is complete if i >= k - 1: result.append(nums[dq[0]]) return result

Comprehensive Complexity Analysis:

  • Deque Solution: O(n) time, O(k) space - optimal for single query
  • Segment Tree: O(n log n) preprocessing, O(log n) per query
  • Sparse Table: O(n log n) preprocessing, O(1) per query
  • Key Insight: Monotonic deque maintains candidates efficiently
  • Amortized Analysis: Each element added/removed at most once

7. Merge Intervals

Medium

Problem Statement:

Given a collection of intervals, merge all overlapping intervals. Handle edge cases and optimize for both time and space.

Example: [[1,3],[2,6],[8,10],[15,18]] → [[1,6],[8,10],[15,18]]

Expected Skills: Sorting, interval processing, optimization

Solution Strategy:

  1. Sort by start time: Process intervals in order
  2. Merge overlapping: Compare current with last merged
  3. Edge cases: Empty input, single interval, no overlaps
def merge_intervals(intervals): if not intervals: return [] # Sort by start time intervals.sort(key=lambda x: x[0]) merged = [intervals[0]] for current in intervals[1:]: last = merged[-1] # Check if intervals overlap if current[0] <= last[1]: # Merge intervals merged[-1] = [last[0], max(last[1], current[1])] else: # No overlap, add current interval merged.append(current) return merged

Analysis:

  • Time: O(n log n) due to sorting
  • Space: O(1) excluding output array
  • Optimization: Could use O(n) if intervals pre-sorted

8. Prime Factorization & Applications

Medium

Implement efficient prime factorization and use it to solve: GCD, LCM, counting divisors, and checking perfect powers.

Advanced Techniques:

  1. Trial Division: Basic approach up to √n
  2. Pollard's Rho: For large composite factors
  3. Sieve Integration: Precompute small primes
  4. Applications: GCD, LCM, divisor counting
def prime_factorization(n): factors = {} d = 2 # Handle factor of 2 while n % 2 == 0: factors[2] = factors.get(2, 0) + 1 n //= 2 # Check odd factors d = 3 while d * d <= n: while n % d == 0: factors[d] = factors.get(d, 0) + 1 n //= d d += 2 # If n is still > 1, it's a prime factor if n > 1: factors[n] = 1 return factors def gcd_from_factors(factors_a, factors_b): gcd = 1 for prime in set(factors_a.keys()) & set(factors_b.keys()): gcd *= prime ** min(factors_a[prime], factors_b[prime]) return gcd

  • Time: O(√n) for trial division
  • Advanced: O(n^1/4) with Pollard's Rho
  • Applications: GCD, LCM in O(log min(a,b))

def extended_gcd(a, b): if a == 0: return b, 0, 1 gcd, x1, y1 = extended_gcd(b % a, a) x = y1 - (b // a) * x1 y = x1 return gcd, x, y def chinese_remainder_theorem(remainders, moduli): if len(remainders) != len(moduli): return None # Check if moduli are pairwise coprime n = len(remainders) for i in range(n): for j in range(i + 1, n): if extended_gcd(moduli[i], moduli[j])[0] != 1: return None # Not pairwise coprime total_mod = 1 for mod in moduli: total_mod *= mod result = 0 for i in range(n): Mi = total_mod // moduli[i] gcd, yi, _ = extended_gcd(Mi, moduli[i]) result = (result + remainders[i] * Mi * yi) % total_mod return result def fast_power_mod(base, exp, mod): result = 1 base = base % mod while exp > 0: if exp % 2 == 1: result = (result * base) % mod exp = exp >> 1 base = (base * base) % mod return result

12. Huffman Coding & Optimal Prefix Codes

Medium

Problem Statement:

Given character frequencies, build optimal prefix-free code using Huffman's algorithm. Analyze compression ratio and prove optimality.

Example: Frequencies {'A':45, 'B':13, 'C':12, 'D':16, 'E':9, 'F':5}

Expected Skills: Greedy algorithms, priority queues, tree construction, proof techniques

import heapq from collections import defaultdict, Counter class HuffmanNode: def __init__(self, char=None, freq=0, left=None, right=None): self.char = char self.freq = freq self.left = left self.right = right def __lt__(self, other): if self.freq == other.freq: # Tie-breaking for deterministic results if self.char is None and other.char is None: return False if self.char is None: return False if other.char is None: return True return self.char < other.char return self.freq < other.freq def build_huffman_tree(frequencies): if len(frequencies) == 1: # Special case: single character char = list(frequencies.keys())[0] root = HuffmanNode(char, frequencies[char]) return root # Create priority queue with leaf nodes heap = [] for char, freq in frequencies.items(): heapq.heappush(heap, HuffmanNode(char, freq)) # Build tree bottom-up while len(heap) > 1: left = heapq.heappop(heap) right = heapq.heappop(heap) merged = HuffmanNode( freq=left.freq + right.freq, left=left, right=right ) heapq.heappush(heap, merged) return heap[0] def generate_codes(root): if root is None: return {} if root.char is not None: # Single character case return {root.char: '0'} codes = {} def dfs(node, code): if node.char is not None: codes[node.char] = code return if node.left: dfs(node.left, code + '0') if node.right: dfs(node.right, code + '1') dfs(root, '') return codes def huffman_encoding(text): if not text: return "", {} # Calculate frequencies frequencies = Counter(text) # Build Huffman tree root = build_huffman_tree(frequencies) # Generate codes codes = generate_codes(root) # Encode text encoded = ''.join(codes[char] for char in text) return encoded, codes def calculate_compression_ratio(text, codes): original_bits = len(text) * 8 # ASCII encoding compressed_bits = sum(len(codes[char]) for char in text) return compressed_bits / original_bits

Analysis:

  • Time: O(n log k) where k = unique characters
  • Space: O(k) for tree and codes
  • Optimality: Huffman codes are optimal for character-based compression

recurse strongconnect(successor) lowlinks[node] = min(lowlinks[node], lowlinks[successor]) elif on_stack[successor]: # Successor is in stack and hence in current SCC lowlinks[node] = min(lowlinks[node], index[successor]) # If node is root node, pop stack and generate SCC if lowlinks[node] == index[node]: scc = [] while True: w = stack.pop() on_stack[w] = False scc.append(w) if w == node: break sccs.append(scc) for node in graph: if node not in index: strongconnect(node) return sccs def maximum_bipartite_matching(graph, left_nodes, right_nodes): """Ford-Fulkerson for maximum bipartite matching""" match_left = {} match_right = {} def dfs(u, visited): for v in graph.get(u, []): if v in visited: continue visited.add(v) # If v is free or we can find an augmenting path if v not in match_right or dfs(match_right[v], visited): match_left[u] = v match_right[v] = u return True return False matching = 0 for u in left_nodes: if dfs(u, set()): matching += 1 return matching, match_left

📊 Quick Reference: Algorithm Complexity

Sorting Algorithms
  • Quicksort: O(n log n) avg

  • Binary Heap: O(log n)
