Module 6: Maze Navigator

Top-Down Movement & Maze Solving

📹 Tutorial Video

🎯 Learning Objectives

  • Create smooth 8-directional movement (including diagonals)
  • Build a challenging maze with walls and paths
  • Implement collision detection for maze walls
  • Create a goal/exit area for the maze
  • Master top-down navigation mechanics

🎮 The Game: Maze Navigator

Create a top-down maze navigation game where the player must find their way from the starting point to the exit. Focus on pathfinding and spatial reasoning!

🔧 Core Nodes

  • TopDownController: Player with 8-directional movement
  • StaticBody2D: Maze walls and barriers
  • Area2D: Goal/exit zone detection
  • TileMap: (Recommended) For creating maze layouts efficiently

🎹 Top-Down Controls

  • WASD: 8-directional movement (including diagonals)
  • Arrow Keys: Alternative movement controls
  • Smooth movement in all directions

🧱 Maze Design Principles

  • Start Area: Clear starting position for the player
  • Exit Area: Visible goal that triggers win condition
  • Dead Ends: False paths that add challenge
  • Multiple Routes: Several valid paths to the exit

🏗️ Building Your Maze Navigator

Step 1: Use Your Existing Player Character

♻️ Reuse Previous Work

Important: Instead of creating a new controller from scratch, instance your existing player character from previous modules. This saves time and maintains consistency across your projects!

  1. Open Previous Project: Navigate to your previous module's player character scene (e.g., "Player.tscn" or "Character.tscn")
  2. Check the Scene: Make sure it has CharacterBody2D with Sprite2D, CollisionShape2D, and Camera2D
  3. Copy to Current Project: File → Export → Copy the player scene file to your Module 6 project folder
  4. Or Instance Directly: If working in the same project, you can directly instance the existing player scene
  5. Rename if Needed: You can rename it to "TopDownController" to match this module's naming

💡 Pro Tip: Reusing assets and scenes is a fundamental game development practice. It ensures consistency and speeds up development!

Step 2: Main Maze Scene Setup

  1. New Game Scene: Scene → New Scene → 2D Scene
  2. Rename Root: Select Node2D → rename to "MazeGame"
  3. 💾 Save immediately: Ctrl+S → Name it "MazeNavigator.tscn"
  4. Instance Controller: Right-click MazeGame → Instance Child Scene → Select "TopDownController.tscn"
  5. Position Player: Drag player to the starting area of your maze
  6. 💾 Save again: Your maze base is ready!

Step 3: Create Maze Walls Using TileSet

♻️ Reuse Your Previous TileSet

Save Time: If you created a tileset in a previous project, you can reuse it here! Tilesets are perfect for building mazes efficiently.

📁 Saving TileSet from Previous Project:

  1. Open Previous Project: Go to your previous project that has a TileMap with walls/platforms
  2. Find the TileSet: Select your TileMap node → Inspector → TileSet property
  3. Save TileSet Resource: Click the dropdown arrow next to the TileSet → "Save As" → Name it "MazeTileSet.tres"
  4. Copy to New Project: Copy the .tres file to your Module 6 project folder

🏗️ Using TileSet for Maze:

  1. Add TileMap: Right-click MazeGame → Add Child → TileMap
  2. Load TileSet: Select TileMap → Inspector → TileSet → Load → Select your "MazeTileSet.tres"
  3. Paint Maze Walls: Use the TileMap painting tools to create your maze layout
  4. Create Paths: Leave empty spaces for the player to navigate through
  5. Add Variety: Use different wall tiles to make the maze visually interesting

🎯 Maze Design: Create a clear starting area, multiple paths with dead ends, and a visible exit area. Make sure there's at least one valid path from start to finish!

Step 4: Create Exit Goal Area

  1. Add Goal Area: Right-click MazeGame → Add Child → Area2D → Rename to "ExitGoal"
  2. Add Visual: Right-click ExitGoal → Add Child → Sprite2D → Use bright/distinct texture (like a door or portal)
  3. Add Collision: Right-click ExitGoal → Add Child → CollisionShape2D → New RectangleShape2D
  4. Size Collision: Make it large enough for easy player detection
  5. Position Goal: Place it at the end/exit of your maze
  6. Add to Group: Select ExitGoal → Groups tab → Add to "goals" group

🎯 Win Condition: When the player touches the ExitGoal, show a "You Win!" message or load the next level.

🎨 Maze Design Ideas

Make Your Maze Challenging!

  • Timer Challenge: Reach the exit before time runs out
  • Multiple Exits: Several exit points, only one is real
  • Dead End Traps: False paths that lead nowhere
  • Different Sized Mazes: Start small, increase complexity
  • Visibility Fog: Only see a small area around the player
  • Breadcrumb Trail: Show where the player has been
  • Minimap Display: Small overview of the entire maze

🐛 Common Problems & Solutions

  • Diagonal movement too fast: Use velocity.normalized() * speed
  • Jittery movement: Apply delta time to movement calculations
  • Getting stuck in walls: Adjust collision shape size
  • Camera not following: Ensure Camera2D is child of player and set to "Current"
  • Movement feels sluggish: Increase speed variable or reduce friction
